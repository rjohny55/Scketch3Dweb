# Scketch3Dweb 1.0.10

First public Linux and Windows desktop release.

## Downloads

Get the files from [release v1.0.10](https://github.com/rjohny55/Scketch3Dweb/releases/tag/v1.0.10):

- **Windows x64:** `Scketch3Dweb-Setup-1.0.10-x64.exe`.
- **Linux x64:** `Scketch3Dweb-1.0.10-x86_64.AppImage` or `Scketch3Dweb-1.0.10-amd64.deb`.
- **SHA256SUMS.txt:** checksums for the downloadable application packages and updater files.

Docker and a separate Node.js installation are not required. The application starts its own web service on loopback, not on the public network. Create your first administrator account when opening the app.

## Changes

## Installation

### Linux

For AppImage:

```sh
chmod +x Scketch3Dweb-1.0.10-x86_64.AppImage
./Scketch3Dweb-1.0.10-x86_64.AppImage
```

AppImage needs FUSE support. If FUSE is unavailable, use the Debian/Ubuntu package or the AppImage extraction mode. Install the Debian/Ubuntu package with:

```sh
sudo apt install ./Scketch3Dweb-1.0.10-amd64.deb
```

Run the installed application as a regular user, not root. Keep Chromium's sandbox enabled.

### Windows

Run the x64 setup executable on Windows 10/11 and choose the installation folder. These builds do not carry a code-signing certificate. Windows may display an unknown-publisher or SmartScreen warning. Only use files downloaded from this repository and verify their checksums.

In PowerShell:

```powershell
Get-FileHash .\Scketch3Dweb-Setup-1.0.10-x64.exe -Algorithm SHA256
```

On Linux, download `SHA256SUMS.txt` alongside the release files and use `sha256sum --check --ignore-missing SHA256SUMS.txt`.

## Data and compatibility

The desktop package includes the editor and local account/project services. The standalone MCP transport bridge is not bundled in this release; use the repository's source/Docker setup when you need that bridge.

The desktop application stores server-side data in Electron's per-user application-data directory, under `projects` and `models`. Browser working copies remain in the desktop browser profile. Keep that profile when upgrading; do not delete it as a way to update the app.

Older differently named applications and Docker/browser installations are not migrated automatically. Export important projects as SKF before moving to a different installation. Closing the window hides the app in the tray; use the tray's Quit command to exit completely.

Application code is MIT OR Apache-2.0. Third-party components and catalog assets retain their own licenses.
