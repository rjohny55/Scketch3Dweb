# Scketch3Dweb 1.0.12

More precise measurements and flange positioning, with a clearer editing history.

- Ruler points follow mesh deformation, including unnamed side walls. Bindings survive save/reopen and undo/redo.
- Magnetic snapping to real outer and inner corners and face edges, even with display contours hidden. Edge retention reduces jumping between adjacent faces. Hold Alt to place a free surface point.
- A dashed preview shows the exact next measurement endpoint. New points cannot be placed in empty space.
- Nearby ruler labels are separated automatically and avoid measurement points. Small leader lines retain their association with each ruler.
- Added bubble-level and measurement-visibility buttons to the ruler submenu. Bubble indicators are enabled by default; hiding measurements does not delete them.
- Enter or a double-click in empty space applies a typed ruler distance. Escape or right-click cancels; losing focus no longer commits the edit.
- Added absolute positioning from fixed reference edges: enter a final vertical/horizontal gap instead of accumulating offsets. Repeating a target does not move the flange again.
- Added `scketch3dweb_set_connection_position` to MCP, with fingerprint guards and preview support.
- Added an operation-history button between Undo and Redo. The journal interleaves model and ruler operations, marks user/agent actions in the current editor session, and supports jumping backward or forward to a selected step. A new edit replaces the undone branch. Older saved steps without author metadata are identified as saved history, not attributed to a guessed author.
- Refreshed the flange demo from the current local fitted model: 53 mm axial span, X rotation 90°, and 12 saved measurements. Updated flange previews and replaced the README's generic assembly screenshot with the built-in RP1 robot.

## Downloads

- Windows x64: `Scketch3Dweb-Setup-1.0.12-x64.exe`
- Linux x64: `Scketch3Dweb-1.0.12-x86_64.AppImage` or `Scketch3Dweb-1.0.12-amd64.deb`
- `SHA256SUMS.txt`: checksums for application and updater assets.

The desktop packages include Electron and a local web service. Docker and a separate Node.js installation are not required. Existing projects remain in the user profile. Builds are unsigned; Windows may show an unknown-publisher warning.

Changing a complete fan flange diameter while preserving bolt-hole diameters is not included in this release. The MCP hole editor changes individual recognized through holes; it is not a substitute for adapting an entire fan interface.

## Verification

TypeScript checking and 452 unit tests passed. Browser checks covered overlapping labels, bubble/visibility toggles, zoom/resize, editable labels, corner/edge snapping, and mixed model/ruler history rollback, redo and branch replacement.

The packaged Linux application passed editor/WebGL, account creation, GitHub link, updated flange demo, and restart/login checks. Packaged Linux and Windows local services passed health, account and database checks; the Windows service was exercised under Wine with HTTP requests driven from Linux.

Windows packages are cross-built on Linux. A native Windows installer/desktop acceptance test remains outstanding.
