# Scketch3Dweb 1.0.13

Extend a mounting flange without stretching the entire duct.

- Added end-face pulling with a preview, drag handle and named face selection.
- The local stand-off mode keeps the duct and opposite mounting face fixed. The selected plate and its bolt holes move together.
- Face picking reports invalid selections instead of silently doing nothing. Protected regions, minimum transition lengths and stale-result guards prevent unsafe edits.
- Updated the built-in CMP 170 / 120 mm fan adapter from the owner's latest saved fitted project. The editable demo retains its current orientation and measurements; SKF and STL downloads use the same geometry.
- Arrow-key holds finish as a single undo step and save. Autosave reuses unchanged mesh, B-Rep, image and CAD display-edge data across history states.
- SKF format 2 shares display-edge assets. Earlier format 1 projects remain readable; newly saved projects require an updated reader.

The bundled demo contains only the active model, not the owner's private project history or account data. Verify mounting clearances and slicer settings before printing.

## Verification

All 461 unit tests and the production web build passed. Browser checks opened the updated demo with 12 measurements and two valid named mounting faces, without JavaScript errors. Mesh checks found no open boundaries, non-manifold edges, inconsistent winding or degenerate triangles.

## Desktop downloads

Linux x64: AppImage and Debian/Ubuntu `.deb`. Windows x64: `.exe` installer. The packages include Electron and a local web service; Docker and a separate Node.js installation are not required. Existing projects stay in the user profile.

Packages are unsigned. Verify downloads against `SHA256SUMS.txt`. Windows packages are cross-built on Linux; a native Windows desktop acceptance test remains outstanding.
