# Scketch3Dweb 1.0.14

- Create an independent project copy from the three-dot menu on the home page. Geometry, measurements, workspace settings, attachments and undo history are preserved; the original project and its sharing permissions stay unchanged.
- Rename projects from the same menu. Saving now finishes before the dialog closes, and a failed save keeps the entered name available for retry.
- Copy names avoid collisions. Both actions are available in English and Russian.

Desktop downloads: Linux AppImage / DEB, Windows installer, and macOS application ZIPs for Intel and Apple Silicon. The macOS packages use ad-hoc signatures, without Developer ID signing or notarization; their startup has not been tested on a Mac.
