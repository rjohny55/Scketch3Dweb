СМЕЩЕНИЕ ОТНОСИТЕЛЬНО ГРАНИ — 28.10.2026

1. Выберите одну деталь. Для группы сначала выполните разгруппировку.
2. В «Метки граней» подпишите две плоские грани. Имена произвольные:
   инструмент не зависит от вентилятора, видеокарты или типа импортированной модели.
3. В свойствах откройте «Смещение относительно грани».
4. Выберите «Неподвижная грань» и «Подвижная грань».
5. Укажите два поперечных смещения, мм. Для текущего патрубка это Y (высота)
   и Z (вбок). Для наклонных граней используются направления U/V.
6. Защищённые участки возле каждой выбранной грани остаются жёсткими.
   По умолчанию защита 2 мм с каждой стороны; подберите её под толщину крепления.
7. «Предпросмотр» показывает результат без изменения модели.
   «Применить смещение» меняет реальную сетку; это одно действие Ctrl+Z.
   Значения задают итоговое смещение от начала текущего сеанса, в том числе после применения.
8. «Совместить центры фланцев» заполняет поля смещения; применение отдельно.
   Совмещаются поперечные координаты геометрических центров граней.
   Продольное расстояние и углы самих креплений сохраняются.

Для патрубка: неподвижной выберите сторону вентилятора, подвижной — видеокарту.
Перестраиваются наружные стенки и внутренний канал одновременно.
Модель автоматически на пол не переносится: фиксированная грань сохраняет мировые координаты.

Поддерживаются разнесённые плоские грани, включая наклонные и некрайние.
Соприкасающиеся/пересекающиеся грани и перекрывающаяся защита отклоняются:
невозможно оставить две такие грани жёсткими при разных смещениях без разрыва.
Криволинейная поверхность не является одной плоской гранью.
Смещение не поддерживает заданную постоянную толщину стенки: после больших
изменений проверьте толщину перехода в слайсере. Замкнутость сетки проверяется перед применением.

НОВЫЕ ЖЕСТЫ
Двойной левый щелчок по готовому размеру рулетки в режиме камеры/просмотра
сразу открывает редактирование. Enter или щелчок вне поля применяет размер;
Esc отменяет. Для изменения корпуса точки должны лежать на противоположных
крайних гранях одной детали; сохраняется прежняя защита концевых участков.
Двойной правый щелчок в рабочей области прекращает рисование отверстия,
сбрасывает незавершённый контур и включает камеру. Одиночное правое
перетаскивание сохраняет управление камерой.

MCP
HTTP-адрес и ключ остаются в настройках приложения; ключ в этот файл не копируется.
После обновления страницы доступны 34 команды, в том числе 10 новых:
  scketch3dweb_read_connections — грани, центры, направления U/V, fingerprint;
  scketch3dweb_offset_connection — смещение с неподвижной гранью, preview или применение;
  scketch3dweb_stretch_object — растяжение середины с жёсткими концами;
  scketch3dweb_rotate_on_floor — поворот/укладка опорной гранью на пол;
  scketch3dweb_read_holes — распознанные отверстия и система локальных координат;
  scketch3dweb_edit_hole — добавить/изменить/заполнить отверстие;
  scketch3dweb_draw_object — прямоугольное тело, цилиндр, треугольная призма;
  scketch3dweb_paint_face — цвет грани по её метке;
  scketch3dweb_edit_face_label — переименовать/удалить метку;
  scketch3dweb_clear_modeling_preview — убрать предпросмотр.
В scketch3dweb_update_object также доступны hidden и locked.

Пример последовательности (вместо заполнителей подставить актуальные ответы):
scketch3dweb_read_connections({"editorNumber":38242,"id":"OBJECT_ID"})
В connections найти id неподвижной и подвижной граней, а в connectionFrames —
соответствующую пару fixedFaceId/movingFaceId и её векторы u/v.
Затем:
scketch3dweb_offset_connection({"editorNumber":38242,"id":"OBJECT_ID",
 "expectedFingerprint":"FRESH_FINGERPRINT","fixedFaceId":"FIXED_FACE_ID",
 "movingFaceId":"MOVING_FACE_ID","keepFixed":2,"keepMoving":2,
 "offsetU":10,"offsetV":-5,"preview":true})
Применение — та же команда с preview:false, если модель не менялась.
Для центрирования вместо offsetU/offsetV можно передать mode:"center".
После каждого применения читать свежий fingerprint; устаревший отклоняется.
Операции выполняются внутри браузерного редактора, сохраняют SKF и поддерживают отмену.
